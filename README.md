# Ecommerce Website
A full stack ecommerce web application built with React, Node.js, and MySQL.

## Tech Stack
- **Frontend:** React, CSS
- **Admin Panel:** React
- **Backend:** Node.js, Express
- **Database:** MySQL

## Features
- Product listing and search
- Shopping cart
- User login and signup
- Admin dashboard
- Add, list, and manage products
- Product image upload

## Folder Structure
ecommerce-website/
├── frontend/   # Customer facing React app
├── admin/      # Admin panel React app
└── backend/    # Node.js + Express + MySQL API

## Getting Started
### Backend
cd backend
node index.js

### Frontend
cd frontend
npm start

### Admin
cd admin
npm run dev
cd admin
npm install
npm run dev
